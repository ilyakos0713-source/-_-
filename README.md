# Excel - оптимизация и финансовые модели

## Размещение участников конференции в Бостоне

Разработана аналитическая модель выбора жилья для 150 участников на три дня.

- 392 объекта размещения;
- 332 886 календарных записей;
- 243 уникальных трёхдневных окна;
- 111 выбранных апартаментов;
- стоимость сценария 66 468 долларов;
- экономия относительно лимита 70 000 долларов - 3 532 доллара, или 5,05%.

Использованы INDEX/MATCH, VLOOKUP, IFERROR, SUMIFS, COUNTIFS, AVERAGEIFS, SUMPRODUCT, нормализация показателей и взвешенная оценка качества.

Важно: выбранный сценарий имеет оценку удовлетворённости 7,84 при исходном целевом значении не ниже 8. Перед публикацией модель необходимо либо переоптимизировать, либо явно представить как компромисс между стоимостью и качеством.

## Экспансия ресторанной сети в США

В составе команды построена юнит-экономика 26 продуктов для восьми городов. Excel-модель учитывает локальные цены на ингредиенты и труд, средний заказ, себестоимость, прибыль и маржинальность.

Расчётная прибыль на заказ:

- Portland: 4,90 доллара;
- Cleveland: 3,62 доллара;
- Cincinnati: 3,07 доллара;
- Indianapolis: 1,96 доллара;
- Columbus: 1,90 доллара;
- Las Vegas: -0,50 доллара.

Связка Excel и Python использована для приоритизации городов и выбора 13 зон размещения в Portland, Cleveland, Columbus, Indianapolis и Cincinnati.
