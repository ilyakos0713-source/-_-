# Прогнозирование исходов футбольных матчей

Интерактивный аналитический проект для сравнения двух футбольных команд и расчёта вероятностей трёх исходов: победы хозяев, ничьей и победы гостей. В работе использованы European Soccer Database, SQL, Python, scikit-learn и Tableau.

[Все материалы проекта](https://drive.google.com/drive/folders/17WXoaVYhHdZcya5Fpag5wBHXhbJ7L9-i)

## Данные

- 25 979 исторических матчей;
- 296 команд из 11 европейских лиг;
- 7 исходных таблиц;
- 25 042 наблюдения с полным набором признаков для моделирования;
- 8 138 потенциальных матчей 2017 года для расчёта прогноза.

## Реализовано

- В SQL объединены данные о матчах, лигах, командах, игроках и их характеристиках. Для каждого матча рассчитаны средний рейтинг стартовых составов, возраст игроков, форма команд за последние пять игр, тактические показатели и коэффициенты Bet365.
- При подготовке признаков использовались только данные, доступные до даты матча: для рейтингов и тактики выбирался последний предшествующий срез, а текущая игра не включалась в расчёт формы.
- В Python обучена модель Random Forest из 100 деревьев. В модель вошли три признака: разница рейтингов составов, разница очков за последние пять матчей и количество голов, пропущенных хозяевами за тот же период.
- Для 8 138 возможных пар команд рассчитаны прогнозируемый исход и вероятности победы хозяев, ничьей и победы гостей.
- В Tableau разработан интерактивный дашборд с выбором команд и сезона, сравнением ключевых характеристик и визуализацией распределения вероятностей.
